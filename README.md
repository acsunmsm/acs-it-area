## 💻 International Student Chapter ACS UNMSM (Área de TI)

Este proyecto corresponde al desarrollo y mantenimiento de la página web del Chapter, enfocándose en mejorar la experiencia digital de los miembros y la comunidad.

Los objetivos principales del área de TI son:  
- Diseñar y mantener la página web para que los miembros puedan registrarse, acceder a eventos y recibir información actualizada.  
- Implementar funcionalidades como formularios de registro, visualización de eventos y gestión de usuarios.  
- Contribuir al desarrollo de herramientas digitales que faciliten la organización y difusión de actividades académicas y científicas.  
- Asegurar que la web sea confiable, accesible y segura para todos los usuarios. 

Este es un proyecto [Next.js](https://nextjs.org) iniciado con [`create-next-app`](https://nextjs.org/docs/app/api-reference/cli/create-next-app).

## 🏁 Primeros pasos para contribuir con el proyecto

Para contribuir a mejorar este proyecto, sigue estos pasos:

1.  **Crea una rama:** Clona el repositorio y crea una nueva rama para tus cambios.
    ```bash
    git checkout -b feature/tu-caracteristica-nueva
    ```
2.  **Haz tus cambios:** Implementa las mejoras o correcciones que desees.
3.  **Haz un 'commit':** Guarda tus cambios con un mensaje claro.
    ```bash
    git commit -m "feat: agrega tu nueva característica"
    ```
4.  **Sube tus cambios:** Sube tu rama al repositorio remoto.
    ```bash
    git push origin feature/tu-caracteristica-nueva
    ```
5.  **Crea un Pull Request (PR):** Abre un Pull Request a la rama `main` del repositorio para que podamos revisar tus cambios.

### Instala las dependencias
Instala Node.js para hacer más facil la instalación de las dependencias necesarias.

Luego, instala las dependencias del proyecto:

```bash
npm install
# o
npm install --global yarn
# o
npm install -g pnpm
# o
npm install -g bun
```

Finalmente, ejecuta el servidor de desarrollo:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Abre tu navegador y navega a [http://localhost:3000](http://localhost:3000) para ver el resultado.

Puedes empezar a editar la página modificando `app/page.js`. La página se actualiza automáticamente a medida que editas el archivo.

Este proyecto utiliza [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) para optimizar y cargar automáticamente [Geist](https://vercel.com/font), una nueva familia de fuentes para Vercel.

## 📝 Nota
Las variables de entorno se encuentran en el archivo `.env.local` y deben ser configuradas antes de iniciar el proyecto. Estas variables deben ser solicitadas al encargado del área.
